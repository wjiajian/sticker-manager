## 产品结构

应用由两个入口组成：

1. **主窗口**（三栏资料库）：整理、浏览、打标签、查看同步状态。
2. **悬浮球**：常驻屏幕边缘，日常取用表情的快捷入口，不需要打开主窗口。

同步设置继续放在偏好设置的“同步”分组，不做独立同步设置页。已设置同步时，标题栏状态按钮和侧栏同步卡片打开同步详情；未设置时直接打开偏好设置并定位到同步。同步详情只承载状态和常用操作。

## 视觉规范

两个入口使用同一套视觉语言。

### 字体

| 用途 | 字体 |
|---|---|
| 拉丁字符与数字 | Manrope（400 / 500 / 600 / 700） |
| 中文 · macOS | PingFang SC |
| 中文 · Windows | Microsoft YaHei UI → Microsoft YaHei |

字号只用以下几档：12 / 14 / 16 / 18 / 24 / 30（px）。不使用斜体，最粗到 700。

### 颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| 正文 | `#1F1F1F` | 文字、深色按钮、贴纸描边 |
| 次要文字 | `#6B6A66` | 计数、说明文字（对白底 5.4:1） |
| 三级文字 | `#4A4945` | 分组标题、次级按钮文字 |
| 背景 | `#FFFFFF` | 主内容区 |
| 侧栏 / 标题栏 | `#F5F4F0` | 导航区、面板底栏 |
| 详情栏 | `#FAFAF8` | 右侧详情面板 |
| 贴纸底 | `#F3F2EE` | 贴纸格子、分段控件底色 |
| 描边 | `#E2E0D9` | 输入框、次级按钮、卡片边框 |
| 强调色 | `#C2410C` | 主按钮、选中描边、悬浮球角标与进度（白字对比 5.2:1） |
| 同步成功 | `#1E8A4C` | 已同步图标 |

标签圆点色：开心 `#F2B705` · 无语 `#8A8A8A` · 生气 `#E5484D` · 打工 `#3E7BFA` · 回复 `#2BA471` · 晚安 `#7A5AF8` · 猫猫 `#E8572A` · 熊熊 `#A0662F`。

### 间距与圆角

- 间距只用：2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（px）。
- 圆角：macOS 版卡片 12、按钮 8；Windows 版按 Windows 11 习惯收小为卡片 8、按钮 4、标签 2 到 4。
- 嵌套圆角：内层圆角 = 外层圆角 − 间距（结果大于 2 时才生效）。例如悬浮面板外圆角 24、内边距 12，内部搜索框圆角 12。
- 背景一律纯色，不用渐变；卡片不做单边描边。

### 动效

- 统一缓动曲线 `cubic-bezier(0.22, 1, 0.36, 1)`：位置变化 500ms，颜色和透明度变化 300ms。
- 只对 `transform` 和 `opacity` 做动画。
- 悬停：贴纸上移 2px，按钮透明度降到 0.82；按下：缩放到 0.98（悬浮球 0.96）。
- 系统开启"减少动态效果"时，只保留透明度变化。
- 可以获得键盘焦点的可交互元素都有焦点环（2px 强调色描边，外移 2px）；悬浮球不获得焦点。

### 图标

设计稿里的图标是按 Phosphor Regular 风格手绘的（1.75 描边、圆角端点），开发时请换成 [Phosphor Icons](https://phosphoricons.com/) 中的对应图标。贴纸是占位插画，正式版用真实表情图片替换。

## 01 主窗口 · 三栏资料库

左中右三栏，窗口宽度不够时依次往下排。

### 标题栏
- macOS：左侧红黄绿按钮；Windows：左侧应用图标和名称，右侧最小化、最大化、关闭（悬停关闭按钮变红 `#C42B1C`）。
- 中间是全局搜索，可搜表情名、标签和配文，快捷键 macOS ⌘K / Windows Ctrl+K。
- 右侧是同步状态按钮（点击打开同步详情）和主按钮"导入表情"。

### 已实现：同步入口与网络存储

- 偏好设置增加“同步”分组：选择文件夹、加入已有仓库的系统确认、设备名、立即同步、错误原因和停止同步确认。路径沿用仓库路径的截断及复制方式。
- 标题栏按钮显示未设置同步、同步中（有原图传输时显示进度）、已同步、已暂停、同步出错，成功状态使用 `#1E8A4C`；提示中显示后端名称、简短地址、进度和错误；点击在按钮下方打开同步详情（未设置时进入偏好设置）。
- 左栏底部同步卡片显示后端名称、简短地址、本机已知原图总大小（含最近删除）、上次同步时间和 10 分钟内同步过的设备数。未设置时显示“在其他电脑上取用 / 设置同步…”，点击进入设置。
- 同步分组支持同步文件夹、WebDAV、Cloudflare R2、S3 兼容；宽度足够时使用分段控件，窄时使用原生下拉。网络表单包含对应地址字段、“路径（可选）”和密码输入，只设一个“连接”主按钮。连接时表单禁用、可取消；失败保留已填内容到关闭对话框；HTTP WebDAV 显示“密码会以明文传输”。
- 已设置时显示后端类型和地址、凭据已保存、设备名、立即同步、上次同步/错误、停止同步，以及不能更改地址的“重新输入密码”入口。左栏卡片显示后端名称与简短地址；同步分组和标题栏显示原图进度：上传显示已传与总数，下载显示本轮已下载张数（日志分批到达，没有总数）；钥匙串读取失败时不显示“凭据已保存”。
- 已实现暂停同步：托盘、悬浮球右键菜单、同步详情和偏好设置共用暂停 / 继续动作。手动暂停保存在本机，重启保持；继续时立即同步一次。暂停期间本机改动照常记录，标题栏和卡片显示“已暂停”，图标用次要文字色。未设置同步时原生菜单项禁用。
- 已实现按流量计费暂停：WebDAV、R2、S3 兼容默认开启“使用按流量计费的网络时暂停同步”；同步文件夹不显示。计费时暂停自动同步并说明原因，用户仍可手动立即同步一轮；恢复非计费网络时立即同步。
- 已实现同步详情：宽 320，白底、完整描边、卡片圆角；标题栏下方或侧栏卡片上方弹出，包含状态及暂停原因、后端与完整地址、原图进度、上次同步时间、错误全文、等待说明、设备列表，以及立即同步、暂停 / 继续、“同步设置…”。打开后焦点进入面板，Esc 关闭并返回触发按钮，点击外部关闭；不是新窗口或模态对话框。

### 已实现：导入流程

- 选择框、主窗口拖入和悬浮球拖入支持直接选中的 `.zip`，包内递归导入图片；导入文件夹时不展开其中的 `.zip`。忽略包内目录项、`__MACOSX/`、隐藏和系统文件；嵌套压缩包及其他类型跳过。支持 UTF-8 和 GB18030 文件名。
- 单条目实际解压超过 100 MB 失败；整包超过 2 GB 或 10000 个条目时剩余部分失败。损坏的条目只算它自己失败，目录区读不出时整包失败。加密、不支持的压缩方式、损坏原因出现在失败列表，路径显示为“表情包.zip › 子目录/a.png”。
- 全窗口共用一批导入，正在导入时拒绝其他批次。主窗口显示“正在导入 N/总数”、进度条和取消；逐张提交，已导入内容保留，网格每秒逐步刷新。悬浮球导入超过 0.5 秒显示进度，结束后显示约 2 秒结果。
- 独立结果条显示新增、已存在、恢复、跳过和失败摘要，可展开限高滚动的失败列表，持续到关闭或开始下一批。关闭后不占高度。主窗口也显示悬浮球发起的导入结果。
- “给这批表情加标签…”复用详情栏的搜索选择器，支持已有标签、新建标签及连续添加。批次含新增、已存在和恢复的表情，排除失败、跳过；操作幂等且跳过已删除或已不存在的表情。

### 左栏 · 导航（宽 216）
- **资料库**：全部表情、最近使用、收藏、未打标签、最近删除，每项右侧显示数量。Windows 版选中项左侧有一条强调色竖条。
- **标签分组**：标签按分组折叠展示（情绪、场景、角色），不属于任何分组的标签显示在"未分组"下；每个标签前有颜色圆点；分组标题旁的加号用来新建标签。
- **同步卡片**（固定在底部）：当前存储后端与地址、存储用量、上次同步时间、在线设备数。

### 中栏 · 表情网格
- 顶部：标题和筛选后的张数，右侧是类型筛选（全部 / 静态 / 动图）和排序方式，窄时换行。类型筛选是全局状态，在所有视图和搜索中生效，侧栏数量不受影响。第一版不支持视频。
- **排序**：全部表情、收藏、未打标签和标签视图显示排序按钮，提供最近添加（添加时间倒序）、最近使用（最近一次使用时间倒序，未使用的在最后）、使用次数（次数倒序，同次数按最近一次使用时间倒序）和名称（中文拼音、数字自然顺序升序）；同值时保留添加时间倒序。最近使用视图固定按最近一次使用时间倒序，最近删除固定按删除时间倒序，搜索结果固定按相关程度排序，这三处不显示排序按钮。筛选和排序在切换视图、进入或退出搜索时保留，重启后回到全部和最近添加。
- **最近使用**条：只在全部表情视图且不在搜索时显示，跟随类型筛选，不跟随排序；没有符合筛选的已使用表情时隐藏。按最近一次使用时间倒序，最多显示 10 个 64px 小格，只渲染当前宽度放得下的整格；“查看全部 N 张”进入完整的最近使用列表，N 为筛选后的已使用表情数量。
- **表情网格**：格子最小 104px，按窗口宽度自动排列；动图右上角标 GIF，带配文的表情在底部显示文字。
- 单击贴纸选中（白色内圈加强调色外圈），右侧详情跟着切换。
- 格子右键菜单提供复制、复制为文件、在访达 / 资源管理器中显示和删除；Shift+F10 或菜单键在格子左下角打开。删除后选中下一张，最后一张则选上一张；格子原来有焦点时，焦点一起移动。
- **最近删除**：按删除时间倒序，标题下说明“表情会在删除 30 天后彻底删除”。格子底部用白底、次要文字色显示“剩 N 天”，到期显示“即将删除”；右键菜单提供恢复和彻底删除。空状态为“最近删除里没有表情”及“删除的表情会在这里保留 30 天”。

### 右栏 · 详情（宽 264）
- 大图预览，名称，尺寸、文件大小和添加日期。
- 操作：复制（主按钮）、在访达 / 资源管理器中显示、收藏。
- 标签列表，加一个"添加标签"虚线按钮。
- 配文（可编辑）、使用次数（所有设备合计）、上次使用时间、同步情况；Windows 版多一行快捷键说明（Ctrl+C 复制、Ctrl+Shift+C 复制为文件、Delete 删除）。
- 已实现“同步”行：未开启、等待上传、“已在 N 台设备上”；旧表情缺少来源记录时显示“已同步”。最近删除隐藏此行及设备列表。
- 已实现设备列表，与同步详情复用：本机排第一，名字后加“ · 本机”，其他设备按最后同步倒序；macOS 用 Laptop，Windows / 未知用 Desktop。名称截断并提供完整 title，时间显示刚刚、N 分钟前、今天 / 昨天时分或年月日。列表缓存于本机，启动即可显示。
- 已实现使用次数的设备数：多台设备有使用记录时显示“12 次 · 3 台设备合计”。删除按钮继续贴底。
- 普通表情底部放次级“删除”按钮（Trash 图标），内容不足一屏时贴底；提示“移到最近删除，30 天内可以恢复”及 macOS ⌘⌫ / Windows Delete。删除不确认，输入、组字和对话框中不触发表情快捷键。
- 最近删除的详情只提供主按钮“恢复”和次级按钮“彻底删除”，尺寸下显示剩余天数，到期显示“即将彻底删除”；标签与配文只读。彻底删除使用原生警告确认框，说明不可恢复及重新导入会丢失原有标签、配文、收藏和使用次数。

## 06 悬浮球

### 外观
直径 56 的白色圆球，阴影 `0 8px 24px rgba(31,31,31,.2)`，里面是品牌笑脸（底色 `#FFC94A`）。

### 状态

| 状态 | 表现 | 触发 |
|---|---|---|
| 默认 | 白底圆球，笑脸 | 常态 |
| 悬停 | 放大到 1.1 倍，笑脸眨眼，提示"单击展开 · 右键更多" | 鼠标移入 |
| 贴边收起 | 吸附在屏幕边缘只露一半，透明度 0.7，表情变困 | 静止 3 秒后 |
| 同步中 | 外圈显示原图进度，完成后 300ms 淡出 | 有原图传输时 |
| 有新表情 | 朝屏幕内侧的上角显示强调色数字角标 | 其他设备同步来尚未看过的新表情 |
| 拖入图片 | 放大到 72，外面出现虚线圈，提示"松开导入 N 张" | 拖着图片文件经过球 |
| 已展开 | 外圈 3px 强调色描边 | 面板展开时 |

### 操作
- 单击：展开或收起面板。
- 拖动：移动位置，松手后吸附到最近的屏幕边缘。
- 右键：原生菜单（打开主窗口、偏好设置、暂停同步 / 继续同步、隐藏悬浮球、退出）。
- 把图片拖到球上：直接导入，出现在"未打标签"里。

### 已实现

- 独立透明窗口，大小固定为 300×168，球在窗口里的位置只随吸附位置变化；悬停、拖入、提示和收起都不改窗口，避免改尺寸时网页晚一两帧重画造成闪跳。鼠标不在球上时窗口不接收鼠标，透明区域的点击落到下面的窗口。提示默认在球下方并朝屏幕内侧，靠近底部时放在上方。
- macOS 使用不能成为 key 的非激活 NSPanel，关闭 `hidesOnDeactivate`，置顶、跨桌面和全屏空间、不参与窗口循环，单击墙纸显示桌面时留在原处；Windows 使用不可聚焦、置顶、不进任务栏的窗口。
- 原生层轮询鼠标位置和按键（鼠标靠近球或按住时每 16ms，其余每 50ms），处理悬停、超过 4px 的拖动和松手吸附，也检测显示器配置变化；不依赖非 key WebView 的鼠标移动事件。
- 静止 3 秒（可改为 10 秒或不收起）后球移到显示器边缘，只露出宽 28 的一半；窗口始终在显示器可见区域内，不会漏到相邻显示器。悬停、拖动、菜单打开、提示和面板打开期间暂停计时。
- 左右吸附位置与球心高度比例保存在本机设置；显示器消失时回到主显示器的同侧同高度。单击在球内侧展开面板，距离 12，超出可见区域时夹回；再点球收起，固定状态保留。
- 拖入图片直接导入“未打标签”，显示约 2 秒的导入结果，并通知主窗口与面板刷新。全部路径都是支持的图片文件时提示数量，含文件夹或其他类型时只显示“松开导入”。
- 已实现原图传输外圈：外扩 6px、3px 圆头描边，上传按比例、下载固定弧匀速旋转；减少动态效果时改为透明度变化。只同步日志时不显示，结束后 300ms 淡出，贴边收起也保留可见部分。悬停提示显示进度及“单击展开”。面板展开改用球内侧 3px 强调色描边，与外侧进度区分。
- 已实现新表情角标：强调色底、白色 12px 粗体、最小宽 24、2px 白圈；贴右侧在左上，贴左侧在右上，收起也不被边缘截断，超过 99 显示“99+”。首次加入、恢复、合并和本机导入不计；主窗口前台或面板打开时到达的不计。任何入口打开面板、或主窗口获得焦点即清零，重启从 0 开始。
- 球不能获得焦点，因此没有焦点环；键盘用户通过全局快捷键、托盘和主窗口偏好设置操作。

## 06 悬浮球展开面板

宽 360、外圆角 24、内边距 12 的白色面板。从球的位置朝屏幕中间展开，和球垂直居中对齐。

### 已实现：快捷键呼出的表情面板

- 通过 macOS ⌃⌥E / Windows Ctrl+Alt+E 呼出，固定大小 360 × 524，居中显示在鼠标所在屏幕的可用区域内，避开菜单栏和 Dock / 任务栏。
- 数字键 1–8 只在搜索框为空、且不在输入法组字时复制对应的最近使用表情；搜索时数字正常输入。
- 搜索结果替换“最近使用、标签行、当前标签的表情”整个区域，四列滚动显示，默认选中第一张。
- 标签沿用主窗口侧栏顺序，只显示有未删除表情的标签；标签网格固定两行，按最近使用排序，多余内容滚动查看。
- 固定状态和上次选择的标签在本次运行期间保留。固定后复制、拖出和失焦不收起，复制的格子显示约 1.6 秒“已复制”；Esc 和再次按快捷键仍可收起。
- 悬浮球单击从球旁边展开，托盘与快捷键在鼠标所在屏幕居中打开；样式使用 Tailwind 和主题变量。底栏已实现 16px 同步状态图标：已同步 CloudCheck（绿色）、同步中 ArrowsClockwise、已暂停 CloudSlash（次要色）、出错 CloudWarning（强调色）；未设置时隐藏。图标按钮提供状态 title / aria-label，打开主窗口的同步详情，面板沿用现有收起规则。悬停预览尚未实现。

### 内容（从上到下）
1. **搜索框 + 图钉按钮**：展开后搜索框自动获得焦点（显示强调色描边），直接打字就能搜；图钉用来固定面板，固定后不会自动收起。
2. **最近使用**：4 × 2 共 8 格，合并所有设备的使用记录，按最近一次使用时间倒序排列。每格左上角标数字 1 到 8，数字跟着顺序变，按 1 就是上一次用的那张；第一个默认选中。
3. **常用标签**：单行横排，选中的标签是深色底，其他是白底描边，带颜色圆点。
4. **当前标签的表情**：4 × 2 网格。
5. **底栏**：同步状态图标、操作提示"单击复制 · 拖出发送 · Esc 收起"，以及跳到主窗口的链接。

### 悬停预览
鼠标停在某个表情上时，面板左侧弹出 168px 宽的预览卡，显示大图、名称、使用次数和标签。

### 根据使用习惯做的取舍
- **就近展开**：面板贴着球弹出，鼠标移动距离最短。
- **键盘优先**：展开后直接打字搜索，数字键 1 到 8 直接复制，Esc 收起，取用表情可以不碰鼠标。
- **刚用过的放最前**：最近使用排在最上面，按最近一次使用时间排序。
- **标签只占一行**：把纵向空间留给表情本身。
- **单击即走**：单击复制后面板自动收起；拖出去直接发送到聊天输入框。
- **先看再发**：悬停预览大图，避免发错。
- **需要时可固定**：连续挑表情时点图钉，面板不会收起。
