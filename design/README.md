# 表情包管理器 · 界面设计说明

跨平台（macOS / Windows）表情包管理工具的界面设计规范，覆盖表情仓库、分类、最近使用、云端同步四项核心功能。术语以 [GLOSSARY.md](../docs/GLOSSARY.md) 为准，技术选型见 [docs/tech-stack.md](../docs/tech-stack.md)。

## 产品结构

应用由两个入口组成：

1. **主窗口**（三栏仓库）：整理、浏览、设分类、查看同步状态。
2. **悬浮球**：常驻屏幕边缘，日常取用表情的快捷入口，不需要打开主窗口。

同步设置继续放在偏好设置的“同步”分组，不做独立同步设置页。已设置同步时，标题栏状态按钮和侧栏同步卡片打开同步详情；未设置时直接打开偏好设置并定位到同步。同步详情只承载状态和常用操作。

- 偏好设置“通用”里的“外观”分段控件：跟随系统 / 浅色 / 深色，默认跟随系统，改了立即生效，只存在本机。
- 主窗口、表情面板、悬浮球、悬停预览，以及原生的标题栏、右键菜单、警告框和文件选择框一起切换。隐藏着的面板和预览也会更新，下次打开就是新外观；主窗口的原生背景和内容区同色，打开时不闪白底。
- 浅色是上面的原始配色；深色只覆盖同一组变量（`src/styles/global.css`），组件里没有写死的颜色。本文其他地方写的“白底”“白色面板”，在深色外观下都是背景色。

### 间距与圆角

- 间距只用：2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（px）。
- 圆角：macOS 版卡片 12、按钮 8；Windows 版按 Windows 11 习惯收小为卡片 8、按钮 4、分类胶囊 2 到 4。
- 嵌套圆角：内层圆角 = 外层圆角 − 间距（结果大于 2 时才生效）。例如悬浮面板外圆角 24、内边距 12，内部搜索框圆角 12。
- 背景一律纯色，不用渐变；卡片不做单边描边。

### 动效

- 统一缓动曲线 `cubic-bezier(0.22, 1, 0.36, 1)`：位置变化 500ms，透明度变化 300ms。颜色变化不做动画，立即切换：隐藏的面板和预览在切换外观后再打开时，不会先从旧颜色淡入。
- 只对 `transform` 和 `opacity` 做动画。
- 悬停：贴纸上移 2px，按钮透明度降到 0.82；按下：缩放到 0.98（悬浮球 0.96）。
- 系统开启"减少动态效果"时，只保留透明度变化。
- 可以获得键盘焦点的可交互元素都有焦点环（2px 强调色描边，外移 2px）；悬浮球不获得焦点。

### 图标

图标统一用 [Phosphor Icons](https://phosphoricons.com/)（Regular 风格，1.75 描边、圆角端点）。

## 主窗口 · 三栏仓库

左中右三栏，窗口宽度不够时依次往下排。

### 标题栏
- macOS：左侧红黄绿按钮；Windows：左侧应用图标和名称，右侧最小化、最大化、关闭（悬停关闭按钮变红 `#C42B1C`）。
- 中间是全局搜索，可搜表情名、分类和配文，快捷键 macOS ⌘K / Windows Ctrl+K。
- 右侧是同步状态按钮（点击打开同步详情）和主按钮"导入表情"。

### 已实现：同步入口与网络存储

- 偏好设置增加“同步”分组：选择文件夹、加入已有仓库的系统确认、设备名、立即同步、错误原因和停止同步确认。路径沿用仓库路径的截断及复制方式。
- 标题栏按钮显示未设置同步、同步中（有原图传输时显示进度）、已同步、已暂停、同步出错，成功状态使用 `#1E8A4C`；提示中显示后端名称、简短地址、进度和错误；点击在按钮下方打开同步详情（未设置时进入偏好设置）。
- 左栏底部同步卡片显示后端名称、简短地址、本机已知原图总大小（含最近删除）、上次同步时间和 10 分钟内同步过的设备数。未设置时显示“在其他电脑上取用 / 设置同步…”，点击进入设置。
- 同步分组支持同步文件夹、WebDAV、Cloudflare R2、S3 兼容；宽度足够时使用分段控件，窄时使用原生下拉。网络表单包含对应地址字段、“路径（可选）”和密码输入，只设一个“连接”主按钮。连接时表单禁用、可取消；失败保留已填内容到关闭对话框；HTTP WebDAV 显示“密码会以明文传输”。
- 已设置时显示后端类型和地址、凭据已保存、设备名、立即同步、上次同步/错误、停止同步，以及不能更改地址的“重新输入密码”入口。左栏卡片显示后端名称与简短地址；同步分组和标题栏显示原图进度：上传显示已传与总数，下载显示本轮已下载张数（日志分批到达，没有总数）；凭据文件读取失败时不显示“凭据已保存”。
- 已实现暂停同步：托盘、悬浮球右键菜单、同步详情和偏好设置共用暂停 / 继续动作。手动暂停保存在本机，重启保持；继续时立即同步一次。暂停期间本机改动照常记录，标题栏和卡片显示“已暂停”，图标用次要文字色。未设置同步时原生菜单项禁用。
- 已实现按流量计费暂停：WebDAV、R2、S3 兼容默认开启“使用按流量计费的网络时暂停同步”；同步文件夹不显示。计费时暂停自动同步并说明原因，用户仍可手动立即同步一轮；恢复非计费网络时立即同步。
- 已实现同步详情：宽 320，白底、完整描边、卡片圆角；标题栏下方或侧栏卡片上方弹出，包含状态及暂停原因、后端与完整地址、原图进度、上次同步时间、错误全文、等待说明、设备列表，以及立即同步、暂停 / 继续、“同步设置…”。打开后焦点进入面板，Esc 关闭并返回触发按钮，点击外部关闭；不是新窗口或模态对话框。

### 已实现：导入流程

- 选择框、主窗口拖入和悬浮球拖入支持直接选中的 `.zip`，包内递归导入图片；导入文件夹时不展开其中的 `.zip`。忽略包内目录项、`__MACOSX/`、隐藏和系统文件；嵌套压缩包及其他类型跳过。支持 UTF-8 和 GB18030 文件名。
- 单条目实际解压超过 100 MB 失败；整包超过 2 GB 或 10000 个条目时剩余部分失败。损坏的条目只算它自己失败，目录区读不出时整包失败。加密、不支持的压缩方式、损坏原因出现在失败列表，路径显示为“表情包.zip › 子目录/a.png”。
- 全窗口共用一批导入，正在导入时拒绝其他批次。主窗口显示“正在导入 N/总数”、进度条和取消；逐张提交，已导入内容保留，网格每秒逐步刷新。悬浮球导入超过 0.5 秒显示进度，结束后显示约 2 秒结果。
- 独立结果条显示新增、已存在、恢复、跳过和失败摘要，可展开限高滚动的失败列表，持续到关闭或开始下一批。关闭后不占高度。主窗口也显示悬浮球发起的导入结果。
- “给这批表情设分类…”复用详情栏的搜索选择器，支持已有分类和新建分类。批次含新增、已存在和恢复的表情，排除失败、跳过；操作幂等且跳过已删除或已不存在的表情。

### 左栏 · 导航（宽 216）
- **仓库**：全部表情、最近使用、收藏、未分类、最近删除，每项右侧显示数量。Windows 版选中项左侧有一条强调色竖条。
- **分类**：分类按位置顺序平铺，每个分类前有颜色圆点和表情数量；标题旁的加号用来新建分类。右键分类可改名、改颜色、删除；删除时它下面的表情移到“未分类”。
- **同步卡片**（固定在底部）：当前存储后端与地址、存储用量、上次同步时间、在线设备数。

### 中栏 · 表情网格
- 顶部：标题和筛选后的张数，右侧是类型筛选（全部 / 静态 / 动图）和排序方式，窄时换行。类型筛选是全局状态，在所有视图和搜索中生效，侧栏数量不受影响。第一版不支持视频。
- **排序**：全部表情、收藏、未分类和分类视图显示排序按钮，提供最近添加（添加时间倒序）、最近使用（最近一次使用时间倒序，未使用的在最后）、使用次数（次数倒序，同次数按最近一次使用时间倒序）和名称（中文拼音、数字自然顺序升序）；同值时保留添加时间倒序。最近使用视图固定按最近一次使用时间倒序，最近删除固定按删除时间倒序，搜索结果固定按相关程度排序，这三处不显示排序按钮。筛选和排序在切换视图、进入或退出搜索时保留，重启后回到全部和最近添加。
- **最近使用**条：只在全部表情视图且不在搜索时显示，跟随类型筛选，不跟随排序；没有符合筛选的已使用表情时隐藏。按最近一次使用时间倒序，最多显示 10 个 64px 小格，只渲染当前宽度放得下的整格；“查看全部 N 张”进入完整的最近使用列表，N 为筛选后的已使用表情数量。
- **复制后不跳位**：按使用排序的地方（最近使用条和最近使用列表、“最近使用”“使用次数”排序）在复制、拖出或其他设备同步来使用记录后不立即重排，刚用过的格子留在原位；主窗口重新打开，或切换视图、搜索、类型筛选、排序后，才按实际数据重新排序。显示的使用次数照常更新。
- **表情网格**：格子最小 104px，按窗口宽度自动排列；动图右上角标 GIF，带配文的表情在底部显示文字。
- 单击贴纸选中（背景色内圈加强调色外圈），右侧详情跟着切换。
- **多选**：macOS ⌘ 点击、Windows Ctrl 点击把格子加入或移出多选，Shift 点击从上一次点击的格子连选到这一格；没有全选。多选的格子都显示选中外圈，详情栏换成“已选 N 张”和批量操作：普通表情“删除 N 张”，最近删除里“恢复”和“彻底删除”（弹原生警告，写明张数）。点在多选内的格子右键，菜单针对整个多选（删除、恢复、彻底删除 N 张）；点在多选外则只选这一张。⌘⌫ / Delete 删除多选，Esc 回到只保留主选中的一张。多选时复制快捷键不触发，拖出只拖被拖的那一张且保留多选。多选里的表情因同步被删除或被筛选掉时自动移出。最近使用小格只响应单击。
- **撤销删除**：删除（单张或多选）后，标题栏下出现一条与导入结果同款的提示条“已删除“名称”/已删除 N 张表情”和“撤销”，10 秒后自动消失，也可关闭；再次删除则替换为新的提示。撤销把当时实际删掉的表情从最近删除恢复并重新选中，在最近删除视图里撤销时不选中。恢复和彻底删除不提供撤销。
- 格子右键菜单提供复制、在访达 / 资源管理器中显示和删除；Windows 额外保留“复制为文件”。Shift+F10 或菜单键在格子左下角打开。删除后选中下一张，最后一张则选上一张；格子原来有焦点时，焦点一起移动。
- **最近删除**：按删除时间倒序，标题下说明“表情会在删除 30 天后彻底删除”。格子底部用白底、次要文字色显示“剩 N 天”，到期显示“即将删除”；右键菜单提供恢复和彻底删除。空状态为“最近删除里没有表情”及“删除的表情会在这里保留 30 天”。
- **清空最近删除**：最近删除里有表情、且不在搜索时，标题行右侧显示次级按钮“清空最近删除…”，有操作进行中时禁用。点击后弹原生警告：标题“清空最近删除”，正文写明张数、无法恢复、重新导入会作为新表情（分类、配文、收藏和使用次数都不会找回），以及已设置同步时其他设备上也会删除；按钮“全部彻底删除”和“取消”。
  - 删除的是确认那一刻最近删除里的全部表情，不受类型筛选影响。确认期间从其他设备同步来的新删除不受影响，已在其他设备上恢复的跳过。
  - 完成后清空选中，焦点移到中栏标题。

### 右栏 · 详情（宽 264）

## 悬浮球

### 外观
直径 56 的白色圆球，阴影 `0 8px 24px rgba(31,31,31,.2)`，里面是品牌笑脸（底色 `#FFC94A`）。

### 状态

| 状态 | 表现 | 触发 |
|---|---|---|
| 默认 | 白底圆球，笑脸 | 常态 |
| 悬停 | 放大到 1.1 倍，笑脸眨眼，提示"单击展开 · 右键更多" | 鼠标移入 |
| 贴边收起 | 吸附在屏幕边缘只露一半，透明度 0.7，表情变困 | 静止 3 秒后 |
| 同步中 | 外圈显示原图进度，完成后 300ms 淡出 | 有原图传输时 |
| 有新表情 | 朝屏幕内侧的上角显示强调色数字角标 | 其他设备同步来尚未看过的新表情 |
| 拖入图片 | 放大到 72，外面出现虚线圈，提示"松开导入 N 张" | 拖着图片文件经过球 |
| 已展开 | 外圈 3px 强调色描边 | 面板展开时 |

### 操作
- 单击：展开或收起面板。
- 拖动：移动位置，松手后吸附到最近的屏幕边缘。
- 右键：原生菜单（打开主窗口、偏好设置、暂停同步 / 继续同步、隐藏悬浮球、退出）。
- 把图片拖到球上：直接导入，出现在“未分类”里。

### 已实现

- 独立透明窗口，大小固定为 300×168，球在窗口里的位置只随吸附位置变化；悬停、拖入、提示和收起都不改窗口，避免改尺寸时网页晚一两帧重画造成闪跳。鼠标不在球上时窗口不接收鼠标，透明区域的点击落到下面的窗口。提示默认在球下方并朝屏幕内侧，靠近底部时放在上方。
- macOS 使用不能成为 key 的非激活 NSPanel，关闭 `hidesOnDeactivate`，置顶、跨桌面和全屏空间、不参与窗口循环，单击墙纸显示桌面时留在原处；Windows 使用不可聚焦、置顶、不进任务栏的窗口。
- 原生层轮询鼠标位置和按键（鼠标靠近球或按住时每 16ms，其余每 50ms），处理悬停、超过 4px 的拖动和松手吸附，也检测显示器配置变化；不依赖非 key WebView 的鼠标移动事件。
- 静止 3 秒（可改为 10 秒或不收起）后球移到显示器边缘，只露出宽 28 的一半；窗口始终在显示器可见区域内，不会漏到相邻显示器。悬停、拖动、菜单打开、提示和面板打开期间暂停计时。
- 左右吸附位置与球心高度比例保存在本机设置；显示器消失时回到主显示器的同侧同高度。单击在球内侧展开面板，距离 12，超出可见区域时夹回；再点球收起，固定状态保留。
- 拖入图片直接导入“未分类”，显示约 2 秒的导入结果，并通知主窗口与面板刷新。全部路径都是支持的图片文件时提示数量，含文件夹或其他类型时只显示“松开导入”。
- 已实现原图传输外圈：外扩 6px、3px 圆头描边，上传按比例、下载固定弧匀速旋转；减少动态效果时改为透明度变化。只同步日志时不显示，结束后 300ms 淡出，贴边收起也保留可见部分。悬停提示显示进度及“单击展开”。面板展开改用球内侧 3px 强调色描边，与外侧进度区分。
- 已实现新表情角标：强调色底、白色 12px 粗体、最小宽 24、2px 白圈；贴右侧在左上，贴左侧在右上，收起也不被边缘截断，超过 99 显示“99+”。首次加入、恢复、合并和本机导入不计；主窗口前台或面板打开时到达的不计。任何入口打开面板、或主窗口获得焦点即清零，重启从 0 开始。
- 球不能获得焦点，因此没有焦点环；键盘用户通过全局快捷键、托盘和主窗口偏好设置操作。

## 悬浮球展开面板

宽 360、外圆角 24、内边距 12 的白色面板。从球的位置朝屏幕中间展开，和球垂直居中对齐。

### 已实现：快捷键呼出的表情面板

- 通过 macOS ⌃⌥E / Windows Ctrl+Alt+E 呼出，固定大小 360 × 524，居中显示在鼠标所在屏幕的可用区域内，避开菜单栏和 Dock / 任务栏。
- 数字键 1–8 只在搜索框为空、且不在输入法组字时复制对应的最近使用表情；搜索时数字正常输入。

- 搜索结果替换“最近使用、全部表情”整个区域，四列滚动显示，默认选中第一张。

### 内容（从上到下）
1. **搜索框 + 图钉按钮**：展开后搜索框自动获得焦点（显示强调色描边），直接打字就能搜；图钉用来固定面板，固定后不会自动收起。
2. **最近使用**：4 × 2 共 8 格，合并所有设备的使用记录，按最近一次使用时间倒序排列。每格左上角标数字 1 到 8，数字跟着顺序变，按 1 就是上一次用的那张；第一个默认选中。
3. **全部表情**：标题与数量，下方四列网格占满剩余空间，超出区域滚动查看；不再以分类限制下半区内容。
4. **底栏**：同步状态图标、操作提示"单击复制 · 拖出发送 · Esc 收起"，以及跳到主窗口的链接。

### 已实现：悬停预览

- 最近使用、全部表情和搜索结果均支持鼠标预览；键盘选中不触发。停住 400ms 显示，离开 150ms 后收起；正在显示或收起不足 300ms 时，进入另一格立即切换。首次显示只做 300ms 透明度淡入，切换不做动画。
- 卡片宽 168、内边距 12、圆角 16，图片区 144×144、圆角 8、内边距 16。名称一行省略；说明为“用过 N 次”（0 次为“还没用过”），随后显示分类名。先用解码后的缩略图，再异步换原图，动图播放；过期解码和就绪回复会被请求编号丢弃。
- 使用独立透明 preview 窗口，启动时创建并隐藏，固定 296×392，四周为 CSS 阴影留透明边距，卡片顶对齐且高度随说明变化。macOS 为不能成为 key/main、非激活、忽略鼠标的 NSPanel，层级高于面板，跨桌面与全屏；Windows 为置顶、不可聚焦、不进任务栏且忽略鼠标的窗口。窗口不查库，只接收面板传来的显示数据。

- 按下鼠标、开始拖出、滚动、搜索内容变化、键盘操作、面板收起／移动／重新打开立即取消预览；滚动后按首次延迟重新判断鼠标所在格子。正在预览的表情从列表消失就收起，名称、标签与使用次数变化时更新。
- macOS 实测固定面板后切到其他应用，WKWebView 不再收到悬停事件；预览仅在面板有焦点时可用，不使用原生鼠标轮询。
- 预览卡不能获得焦点、不接收鼠标且 `aria-hidden`；面板格子的 `aria-label` 仍为名称，`aria-description` 提供相同的使用次数和分类说明。隐藏 WebView 不等待 rAF，缩略图解码与 DOM 提交后通知 Rust 显示，再淡入；可见时先提交新内容再移动窗口，避免旧内容闪到新位置。

### 根据使用习惯做的取舍
- **就近展开**：面板贴着球弹出，鼠标移动距离最短。

- **新导入也能直接取用**：下半区显示全部表情，不要求先使用或设分类。
- **单击即走**：单击复制后面板自动收起；拖出去直接发送到聊天输入框。
- **先看再发**：悬停预览大图，避免发错。
- **需要时可固定**：连续挑表情时点图钉，面板不会收起。

## 已实现：空状态、加载与读取错误

- 主窗口首次启动的空仓库在中栏居中显示 48px Phosphor 图片图标、“还没有表情”、拖入说明、“导入表情…”与“导入文件夹…”；共用标题栏导入流程，导入中禁用。未设置同步时提供定位到同步分组的链接；快捷键注册成功才显示取用提示。空仓库没有选中项时详情栏留白，拖入仍使用整窗描边。

- 已设置同步、仓库为空，且正在同步（尚无成功同步记录，或正在下载原图）时，主窗口与表情面板显示“正在从同步取回表情”，不显示导入按钮；主窗口复用标题栏的进度文字。
- 读取超过 200ms 才显示骨架：主网格铺满一屏并沿用网格列宽、间距和圆角，侧栏分类为三行圆点与文字条，详情为正方形与两条文字，面板为最近 8 格、3 个分类胶囊和分类表情 8 格。纯贴纸底色，透明度在 1 与 0.6 间以统一缓动曲线按 1.2 秒周期往返；减少动态效果时静止。容器标记 `aria-busy`，配视觉隐藏的 `role=status`，色块 `aria-hidden`。面板搜索和详情同步行保留文字加载提示。
- 主网格读取失败居中显示强调色 WarningCircle、16px 标题、可选择复制且限高滚动的错误全文与“重试”；详情同结构但无图标；侧栏显示“读取分类失败”和文字“重试”。面板保留现有错误条。

## 已实现：检查更新

- 入口只在偏好设置的“更新”分组：当前版本号和“检查更新”按钮，下方一行显示检查中、已是最新版本（附检查时间）、发现新版本（附“查看”，忽略过的标“已忽略”）、下载进度或错误；再下面是“自动检查更新”开关，默认打开，只存在本机。
