## 三种入口

- 点「导入表情」按钮选图片或 `.zip`，可以多选。
- 在按钮旁边的下拉菜单里选「导入文件夹」。
- 把图片、文件夹或 `.zip` 直接拖进主窗口或悬浮球。

导入过程中可以随时取消，已经导入的会保留。

## 支持的格式

PNG、JPG、WebP（包括动图）、GIF、APNG。不支持视频。

## 按文件夹自动分类

导入文件夹时，每张图片会归到它所在那一层文件夹同名的分类里。

- 直接放在所选文件夹里的图片，用这个文件夹的名字。
- 子文件夹里的图片，用子文件夹的名字。
- 已经有同名分类就直接沿用（英文字母不区分大小写），没有就新建。
- 文件夹名不能当分类名的（比如叫「未分类」、以点开头、含 `..`），图片照常导入，留在未分类。

## 单张图片和压缩包

直接选中或拖入的单张图片、`.zip` 都不设分类。导入完成后，可以在导入结果条上点「给这批表情设分类…」，给这一批统一设一个。

`.zip` 会递归导入包里的图片，忽略 `__MACOSX/` 和隐藏文件，文件名支持 UTF-8 和 GB18030（GBK）编码。文件夹里夹带的 `.zip` 不会展开，加密的压缩包不支持。

## 同一张图只存一份

应用按图片内容判断是不是同一张。重复导入不会多出一张，结果条会显示「新增 N 张，M 张已存在」，已经在库里的表情保持原来的名字和分类。

## 删掉后再导入等于恢复

删除的表情在 30 天内再导入同一张图，等于把它从「最近删除」里恢复，原来的分类、配文、收藏都还在。彻底删除之后再导入，就算一张新表情。
