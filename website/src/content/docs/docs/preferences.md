从左栏底部、托盘菜单、悬浮球右键菜单打开，或者按 `⌘,`（Windows 用 `Ctrl+,`）。所有设置在同一页，点左侧目录可跳到对应分区。按 `⌘F` 或 `Ctrl+F` 搜索设置。焦点在搜索框且有内容时，按一次 Esc 清空，再按一次关闭。设置只保存在本机，不会同步。

## 外观

界面外观可选跟随系统、浅色、深色，改了立即生效。主窗口、表情面板、悬浮球、预览，以及系统的菜单和对话框会一起切换。

## 启动

可在这里开关「开机时自动启动」。第一次从「应用程序」这类固定位置打开时默认开启，直接从 DMG 里运行不会登记。开机自启时只显示悬浮球和托盘，不弹出主窗口。

## 悬浮球

显示或隐藏悬浮球，设置静止后多久收到屏幕边缘，调整悬浮球大小（40–80 px）。拖动时可以对照等大的笑脸预览，松手保存。按住滑块时按 Esc 会丢弃预览并关闭设置。

## 表情面板

点击当前快捷键，按下新组合，松开所有按键后保存。按 Esc、Tab 或点“取消”退出录制；搜索筛掉表情面板、录制按钮失焦或超过 60 秒也会退出。可以“恢复默认”或“停用”，停用后仍能用悬浮球和托盘打开面板。

字母、数字、符号和编辑键需要至少两个主修饰键：macOS 从 ⌃、⌥、⌘ 中选两个，Windows 同时按 Ctrl 和 Alt。F1–F12 与空格至少搭配一个主修饰键，F13–F20 可单独使用（macOS 上 F14、F15 留给屏幕亮度）；Windows 还支持 F21–F24。Shift 不算主修饰键，Win 组合与系统保留组合不能使用。

中文输入状态下请先切到英文再录制。若按下组合没有反应，可能已被系统或其他应用占用，换一个组合试试；注册失败时会显示原因，释放冲突后可以点“重试”。

## 同步

选择同步文件夹、WebDAV、Cloudflare R2 或 S3 兼容后端。连接后可以查看状态、复制完整地址或立即同步。展开「管理配置」可修改设备名、暂停或停止同步，网络后端还可重新输入凭据。详见[同步](../sync/)。

## 仓库

点路径旁的复制按钮可复制完整仓库路径。「打开所在位置」会在访达或文件资源管理器中打开仓库。

- **移动位置**：选本机磁盘上的一个空文件夹，应用会复制全部表情和本机设置，检查无误后切换过去，再删除原位置的仓库文件。不要选网盘同步的文件夹（比如 iCloud 云盘、OneDrive）、同步文件夹或网络驱动器。移动期间同步会暂停，导入、导出和退出应用都不可用；复制阶段可以取消，取消后仓库仍在原位置。
- **恢复默认位置**：移动过的仓库可以用同样的方式搬回默认位置。
- Windows 便携版的仓库固定在程序所在目录的 `data` 里，不能移动；要换位置，把整个程序文件夹移走即可。

## 导出

把整个仓库的表情按分类导出到文件夹或 `.zip`。最近删除里的表情，以及配文、收藏和使用次数不会导出。导出进度和结果会直接显示在按钮下方。
