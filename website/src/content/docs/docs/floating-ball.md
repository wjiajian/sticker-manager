## 悬浮球

悬浮球常驻屏幕边缘，初始在主显示器右侧。

- **单击**：展开表情面板。
- **右键**：打开菜单，可以打开主窗口、偏好设置，隐藏悬浮球，暂停或继续同步，退出。
- **拖动**：可以拖到别的位置。静止 3 秒后收到屏幕边缘，也可以在偏好设置里改成 10 秒或不收起。
- **拖入图片**：把图片、文件夹或 `.zip` 拖到悬浮球上也能导入。

Windows 也支持从微信、QQ 等聊天软件拖入图片或虚拟文件。来源没有提供可读取数据时，会提示先保存图片再导入。

## 菜单栏托盘

托盘菜单提供：显示表情面板、打开主窗口、显示悬浮球、偏好设置、暂停或继续同步、退出。有新版本时，菜单最上面会多一项「更新到 x.y.z…」。

## 退出

关闭主窗口只是把它隐藏，应用会继续在后台运行。要完全退出，用托盘或悬浮球菜单里的「退出」，或者按 `⌘Q`。
