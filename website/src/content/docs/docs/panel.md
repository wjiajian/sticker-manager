title: 表情面板
description: 在任何应用里呼出表情面板，搜索、复制和拖出表情。
---

表情面板是平时用得最多的地方。在任何应用里呼出它，搜到表情，复制或拖出去，不用切到主窗口。

## 呼出

- 按 `⌃⌥E`，面板出现在鼠标所在的屏幕上。Windows 上是 `Ctrl+Alt+E`。
- 单击悬浮球。
- 从托盘菜单打开。

快捷键暂时不能修改。

## 搜索和取用

打开后直接输入就能搜索。单击表情复制，或者把表情直接拖进聊天窗口发送。

鼠标停在表情上会弹出大图预览。

## 键盘操作

| 按键 | 作用 |
|---|---|
| 方向键 | 选择表情 |
| 回车 | 复制选中的表情 |
| 1 到 8 | 不在搜索时，复制「最近使用」里对应的那一张 |
| Esc | 收起面板 |

## 固定面板

面板默认在切到别的应用时自动收起。点「固定面板」按钮后，它会一直留在屏幕上。
