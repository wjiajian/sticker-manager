# Windows 验收记录

Windows x64 版在 2026-11-04 完成构建和验收（当时版本 0.1.5）。这里记录验收过什么、范围多大、还有什么没验。构建和打包方法见[打包和发布](packaging.md)。

## 环境

- Windows 11 专业版（系统构建 26300），一块 2560×1440 的屏幕，缩放约 124%。只覆盖这一台机器和这一种缩放。
- 运行验收用 Debug 程序，`STICKER_LIBRARY_DIR` 指向临时仓库；便携版用 Release 程序，靠 `portable.flag` 隔离数据。没有碰真实仓库，没有改系统设置。
- 自动检查：类型检查、前端构建、Rust 格式、Clippy 和全部 Rust 测试在 Windows runner 上通过，8 项需要容器的网络测试按原设置忽略。

## 已验收

| 项目 | 结果和范围 |
|---|---|
| 启动 | 正常启动；`--autostart` 启动时四个页面都加载、主窗口保持隐藏 |
| 标题栏 | 最小化、最大化与还原通过；关闭后窗口隐藏、进程保留；960×600 下布局正常 |
| 导入 | 文件选择器导入 GIF；文件夹 60 张；PNG、JPG、WebP、GIF、APNG 和 ZIP 去重 |
| 整理 | 搜索、配文、收藏、新建分类、设分类、删除和撤销 |
| 剪贴板 | 普通复制含 PNG、CF_DIB、CF_HDROP，PNG 的 alpha 保留；Ctrl+Shift+C 只有文件引用；GIF 原文件哈希一致 |
| 表情面板 | Ctrl+Alt+E 呼出；固定后复制和失焦都不收起，取消固定后失焦收起；Esc 收起；滚动加载第二页 |
| 悬停预览 | 分数缩放下能显示并解码图片；预览不抢焦点，面板不会因此收起 |
| 悬浮球 | 偏好设置里可以隐藏和显示 |
| 外观 | 应用内切换深浅，四个窗口一起更新 |
| 同步文件夹 | 非法文件名给出可操作的错误，改名后同步成功；旧客户端留下的非法移动意图也能恢复 |
| 仓库路径 | 安装版使用 `%APPDATA%\sticker-manager`，从旧标识符目录迁移的优先级和已有数据保护由临时目录测试覆盖 |
| 便携版 | 空仓库启动、导入、整目录搬迁后重启，数据和缩略图都在；不登记自启，检查更新提示手动升级 |
| 聊天软件拖入 | 悬浮球接收本地文件、虚拟文件／文件流、PNG 和 DIB；微信、QQ 的真实拖入由用户验收通过 |
| 标题和任务栏图标 | 标题栏图标和标题放大，任务栏图标减少留白；由用户验收通过 |

## 还没验收
- 按流量计费状态的切换、减少动态效果、跟随系统切换深浅。
- 多屏和其他缩放比例。

## 验收中改过的 Windows 行为

- 主窗口用自绘标题栏：应用图标、名称和最小化、最大化／还原、关闭按钮。
- 分数缩放下预览卡片的尺寸回执先取整再交给原生层校验（216 CSS 像素会被量成约 215.975）。
- 同步状态在 setup 结束前登记，避免 WebView2 提前查询时出现启动竞争。
- 仓库迁移用跨进程文件锁串行化；空的当前目录不遮住更早的仓库；读取出错时报启动错误，不打开空仓库。
- 同步文件夹拒绝 Windows 不允许的文件名，包括 `CONIN$`、`CONOUT$` 这类控制台保留名。
- 慢的拖入来源在 COM 后台线程读取，不卡住界面；拖入登记失败时只是没有这项功能，应用照常启动。
