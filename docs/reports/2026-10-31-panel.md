## 依赖

- `tauri-nspanel = "=2.1.1"`：crates.io 发布版，仅放在 `cfg(target_os = "macos")` 依赖中。它适配 Tauri 2，不需要 Git 依赖或 rev。参考[上游安装说明](https://github.com/ahkohd/tauri-nspanel/blob/v2.1/docs/installation.md)及[发布包](https://crates.io/crates/tauri-nspanel/2.1.1)。
- `tauri-plugin-global-shortcut = "2.4.1"`：crates.io，`Cargo.lock` 锁定 2.4.1。快捷键只在 Rust 注册，不向面板开放注册/修改权限。
- 没有新增前端依赖。平台 API 的 macOS 实现全部以 `cfg` 隔离。

## 界面细节

- 固定尺寸采用 360 × 524 逻辑像素：12px 内边距和区块间距、36px 搜索行、两组 78px 格子及 8px 格间距、32px 标签行和底栏。
- 选中格子的白色内圈与强调色描边放在格子内，避免滚动区裁掉外圈。面板阴影使用系统窗口阴影。
- 数据读取和搜索等待时显示简短状态；操作错误在底栏上方显示，不改变固定尺寸。
- 搜索防抖或组字期间不允许 Enter 复制过期结果。←/→ 有搜索文字时保留光标移动，数字只在输入框完全为空时触发取用。
- 不足 8 张最近使用时不补虚构格子。没有标签时隐藏标签行和对应网格，窗口保持固定大小。
- 从主窗口或面板使用表情都会广播仓库更新，两个窗口的使用数据保持一致。

## 原生实现与说明中的差异

- 使用 crates.io 的 Tauri 2 适配版本，无需 Git rev；本轮功能范围没有扩展。
- macOS 定位全部使用 AppKit 的逻辑坐标：`NSEvent.mouseLocation`、`NSScreen.visibleFrame` 和 `NSPanel.setFrameOrigin`。真机测试发现 Tauri 的物理鼠标坐标不能直接传给逻辑屏幕定位接口，现已避免坐标混用。
- 面板支持未激活时的首次点击；每次取得键盘焦点时显式把 AppKit first responder 交回 WKWebView。真机复测确认固定面板重新聚焦后，直接按数字键可复制。
- 可选的双实例占用实验未产生注册错误。当前插件在 macOS 上使用非独占 `RegisterEventHotKey`，系统接受了两个进程注册同一组合。因此这一实验不能证明错误提示分支；未为测试改变快捷键或引入独占注册机制。
