# 表情管家项目规格

**文档状态：** 首版规格（0.1.x）
**更新时间：** 2026-09-20
**产品定位：** 本地优先的 Windows、macOS 和 Android 图片与 GIF 表情库，支持快速唤出、管理、导入和可迁移备份。

## 1. 目标与边界

表情管家保存用户自己的图片和 GIF 副本，帮助用户在 QQ、微信及其他支持系统剪贴板的应用中快速选择并发送。首版不需要账号、服务器或云端同步；迁移通过加密文件完成。

支持范围：

- Windows 10/11 x64：托盘常驻、全局热键、快速选择窗口、系统剪贴板和模拟粘贴/回车。
- macOS 12 及以上：菜单栏常驻、全局快捷键、快速选择窗口、文件导入和系统剪贴板。
- Android API 28 及以上：系统分享导入、文件导入、系统剪贴板和可选悬浮面板。
- 图片和 GIF；媒体按内容 SHA-256 去重，原始 QQ/微信文件只读。

不在首版范围内：读取 QQ/微信私有数据库、绕过 Android 沙箱、账号体系、云端同步、自动修改源应用文件。

## 2. 核心使用流程

### 2.1 Windows 快速发送

1. 用户在目标聊天输入框所在窗口按 `Ctrl+Shift+E`（可在设置中修改）。
2. 应用在显示自身窗口前记录外部前台窗口，并排除表情管家窗口。
3. 快速选择窗口显示当前分组、搜索框和高密度缩略图网格。
4. 单击表情：写入图片或 GIF 剪贴板，恢复目标窗口，发送 `Ctrl+V` 和 `Enter`；成功后增加使用次数。
5. 双击合并为一次动作。复制失败、目标窗口失效或粘贴失败不计使用次数。

目标窗口捕获在 Windows 原生层完成：`WM_HOTKEY` 到达 runner 时先保存一次前台 HWND 快照，Dart 的热键回调随后只消费这份短时快照。快照冻结进程 PID、窗口类名和标题；QQNT 在发送期间重建 HWND 时，应用只在同一 PID 内枚举可见顶层窗口，并按冻结的类名/标题及窗口状态重解析，避免把输入发到其他进程。激活会短暂重试并验证实际顶层前台句柄，验证未通过就不发送 `Ctrl+V`/回车。

从托盘图标左键/双击打开的是主管理完整窗口。图标点击发生时捕获外部前台窗口，随后完整窗口中的单击表情也可以恢复该一次性目标并粘贴发送；双击产生的重复事件只打开一次窗口，不清除首个点击捕获的目标。右键菜单中的“打开表情管家”是纯管理入口，会清除一次性目标；没有有效目标时，单击只复制到剪贴板并提示结果，不向历史窗口误发，也不把仅复制计入 Windows 使用次数。主管理界面的“快速唤出”按钮可以在用户刚从外部窗口切回、且快照仍在短时有效期内时复用最近外部窗口；超过有效期仍只复制。只有本次入口捕获并通过激活验证的目标才允许自动粘贴发送。

### 2.2 Android 导入与发送

- 从 QQ、微信或文件管理器使用系统分享，将图片复制到应用缓存队列；用户在应用中确认后导入。
- 也可以使用系统文件选择器导入。
- 悬浮面板需要“显示在其他应用上层”权限，最多展示当前排序前 100 个表情；点击后复制到 Android 剪贴板并记录待合并的使用次数。
- GIF 在 Android 端继续使用长按预览，长按不改作管理菜单。

### 2.3 macOS 复制与管理

macOS 默认使用 `Cmd+Shift+E` 显示快速选择窗口，快捷键可在设置中修改。单击表情成功复制后增加使用次数，用户切换到目标应用按 `Cmd+V` 粘贴。静态图提供 PNG 数据，GIF 提供原始 GIF 数据及文件 URL，因此不会因复制而变成单帧图片。macOS 不模拟粘贴或回车，也不读取 QQ/微信私有目录。

macOS 支持卡片右键管理、鼠标框选和 `Cmd` 追加选择。关闭窗口后仍可通过菜单栏图标或 Dock 恢复主管理窗口；菜单栏中的“退出”结束进程。

## 3. 数据与排序

每个表情至少包含：

| 字段 | 规则 |
| --- | --- |
| `id` | 内容哈希前 16 位的稳定标识 |
| `hash` | 原始媒体 SHA-256，唯一去重键 |
| `mediaType` | `image` 或 `gif`，由文件签名判断 |
| `filePath` | 应用私有媒体副本 |
| `thumbnailPath` | 应用生成的 PNG 缩略图，可为空 |
| `source` | `manual`、`qq`、`wechat` 或 `androidShare` |
| `note` | 用户备注；导入时默认为原文件名（无扩展名） |
| `createdAt`/`updatedAt` | 创建和最近修改时间 |
| `lastUsedAt`/`usageCount` | 成功使用记录 |
| `isPinned` | 是否置顶 |
| `thumbnailVersion` | 缩略图生成器版本 |
| `sourceOrder` | QQ 收藏源目录中的顺序，可为空 |

表情与分组是多对多关系。系统创建 `全部` 和 `QQ收藏` 两个分组；每个表情始终属于 `全部`。新建分组后导入时，导入记录同时加入当前选中分组（以及 `全部`）；QQ 来源自动加入 `QQ收藏`。

普通分组和 `全部` 的排序为：置顶优先、使用次数降序、最近使用时间降序、创建时间降序。`QQ收藏` 使用 `sourceOrder` 升序，缺少源顺序的记录排在后面，再以创建时间升序稳定排序。

主管理窗口提供默认规则与“最近导入”两种排序选择。最近导入按创建时间降序排列；恢复默认规则后使用上述分组规则。侧栏数量按分组关系计算，不随搜索变化；内容标题显示当前结果数量。表情可以属于多个分组，因此分组数量之和可能超过全库数量。

搜索范围可选“当前分组”和“全部表情”，默认当前分组。输入会去除首尾空格并忽略大小写，匹配 `note` 和表情 `id`。因此备注为“薇欧拉系列”的表情输入“薇欧拉”应能命中。选择全库范围时，内容标题显示“全部表情”，默认排序采用全库规则；切换侧栏分组后恢复“当前分组”，但是保留关键词和筛选条件。

筛选支持类型（全部、静态图、GIF）、来源（手动导入、QQ、微信、Android 分享）、导入时间和仅置顶。不同条件必须同时满足；来源可多选，满足任意已选来源即可，未选择表示全部。时间依据 `createdAt` 和设备本地日期判断；最近 7 天、最近 30 天均包含今天，自定义范围包含结束日期全天。

桌面通过浮层编辑筛选，移动端通过底部面板编辑。只有“应用”提交条件；“重置”恢复面板中的默认值，因此重置后关闭面板仍保留原有条件。已应用条件显示为单行摘要，按钮数字按生效的条件类别计数。清除搜索只清空关键词，清除筛选只恢复筛选条件。无结果时提供相应的清除操作；范围为具体分组时还提供“搜索全部表情”，但是不会自动扩大范围。筛选不改变当前排序选项，侧栏数量也不随筛选变化。

搜索范围、关键词和筛选只保存在当前会话中，重新启动后恢复默认值。快速选择窗口与主管理窗口共用这些条件，并提供范围选择、筛选和清除操作。

主管理窗口和快速选择窗口均显示一行最近使用，最多包含全库最近成功使用的 20 张不同表情。同一表情再次成功复制、粘贴或发送后移到最前；失败不更新。Windows 独立复制进入最近使用，但是不增加使用次数。因此最近使用单独保存在本机偏好中，不修改频率排序和迁移包字段。

最近使用支持横向滚动，桌面另有左右翻页按钮；图片保持原比例，备注通过悬停提示显示。没有记录、正在搜索或筛选、进入多选模式时隐藏此区域。切换分组不会限制最近使用的范围，删除表情后移除对应记录。设置中的“显示最近使用”默认开启。

设置窗口在切换选项后保持显示，并立即反映已保存的状态。配置项直接显示在设置内，不再使用二级窗口。快捷键描述右侧显示当前组合键，点击后在原位置录入，通过同行下方的保存或取消操作确认或放弃；无效组合键和注册失败会在设置内提示。Windows 兼容性记录直接显示，Android 悬浮面板使用开关。用户可以通过“关闭”或窗口外区域退出设置，未保存的快捷键草稿不生效。

鼠标在表情图片或卡片上停留 500 毫秒后，以浮动提示显示完整备注，长文本自动换行。最近使用采用相同规则，空备注不显示提示。

桌面表情卡片隐藏底部备注文字，并缩小卡片高度。备注通过悬停提示查看；移动端保留备注文字和操作入口。

桌面表情卡片采用正方形，图片区域随卡片尺寸变化，内边距为 4 逻辑像素。图片按原比例尽量填满可用区域，不裁剪或拉伸；移动端另保留备注和操作区域。最近使用保持紧凑的单行卡片，内边距同样为 4 逻辑像素，并与内容区左对齐。桌面翻页按钮位于标题旁；内容未超出一行时隐藏按钮，到达首尾时禁用相应方向。全部表情保留复制和管理操作。

## 4. 导入规则

### Windows QQ/微信

- 自动探测优先使用已确认的路径，其次检查用户文档、OneDrive 文档、应用数据和已知安装布局；对盘符下 `QQ` 目录只逐层确认 `dialogue/Tencent Files`，不依赖固定盘符或版本目录名。
- QQNT 只把 `Tencent Files` 下的纯数字账号目录拼接到 `nt_qq\nt_data\Emoji\personal_emoji\Ori`；`marketface` 和 `emoji-recv` 可作为明确的其他来源候选，但不会把账号根目录递归当作表情目录。
- 旧版 QQ 只检查命名的 `CustomFace` 等表情目录。不会扫描 `D:\QQ\_NT\dialogue\Tencent Files` 这类错误的安装根路径，也不会递归扫描 QQ 安装目录。
- 明确选择的单个目录最多扫描 1,000 个文件。通过 GIF/PNG/JPEG/WEBP/BMP 文件签名确认类型，扩展名缺失也可以导入。
- 导入准备阶段单个文件最多读取 64 MiB，单批次最多读取 512 MiB；超限文件会跳过并在结果中明确计数，避免异常聊天媒体耗尽内存或磁盘。
- 自动导入先展示批次、来源、数量和重复项；用户可以逐文件勾选，避免把群聊记录或接收表情导入收藏。
- 文件先通过内容哈希判断是否已经存在；新图片复制到应用托管目录，重复图片复用已有副本。如果副本缺失或长度与原图不同，则重新写入副本，并保留原记录和分组关系。导入不修改源文件，因此源文件删除不影响已导入副本。

### 共用预览与桌面入口

文件选择、目录扫描、系统分享、桌面拖放和剪贴板导入共用预览与校验。预览显示目标分组、文件列表、新增图片、已有图片加入分组、已存在及跳过项，并说明跳过原因。默认目标是当前分组；全库搜索时默认“全部表情”，用户可以在预览中修改。一次预览中的全部来源共用 512 MiB 上限。

预览阶段不修改表情库，也不创建托管媒体副本。确认后，新图片加入目标分组；重复图片增加尚未具备的目标分组关系，并保留原备注和原分组。结果分别统计新增、已有图片加入分组、已存在和失败数量。源文件在预览后发生变化时，本次导入拒绝该文件，避免导入与确认内容不一致的图片。

Windows 和 macOS 主管理窗口的内容区支持拖入本地文件和文件夹，松开后显示预览。目录使用现有 `ImportSource` 扫描范围和每目录 1,000 个文件上限；无效文件不影响其他有效图片。网页链接不作为图片下载；浏览器必须提供可读取的本地文件或图片数据。侧栏、内部卡片归类和快速窗口不提供拖放导入。

“导入表情”主按钮选择文件，旁边菜单提供从剪贴板导入及目录入口。Windows 使用 `Ctrl+V`，macOS 使用 `Cmd+V`；仅主管理窗口非文本区域处理图片粘贴。文本框保持文字粘贴，弹窗优先处理快捷键。应用只在明确操作后读取剪贴板，不监听剪贴板变化。

剪贴板优先使用本地文件列表，其次读取原始 GIF，再读取 PNG 或位图，因此原始 GIF 不会因为同时存在位图表示而变成静态图。纯图片数据的初始备注为“剪贴板图片＋时间”。文字、网址和不可读取的文件引用分别显示无图片或读取失败说明，并保留原剪贴板内容。拖放和剪贴板属于手动导入来源；确认、取消或失败后清理本次生成的临时图片。导入处理及预览期间拒绝另一次导入。

### Android

Android 不访问 QQ/微信私有目录。分享接收队列在导入确认并成功处理后才清理，进程重启或失败可以重试。
分享 URI 同样受单文件 64 MiB、单批次 512 MiB 限制；来源应用无法提供大小时按流式上限检查，超过限制的文件会保留可见错误提示。

## 5. 缩略图与性能

导入分为文件准备、数据库批量提交和缩略图生成三阶段：文件准备有限并发，数据库一次事务提交，记录提交后立即刷新网格，缩略图在后台有限并发生成。原图无法安全解码时仍保留原始记录，缩略图失败回退到原图或占位，不保存可能带黑块的“尽力解码”结果。

缩略图使用 Flutter 原生图片编解码器生成最长边约 240px 的 PNG；生成器版本变化会在后台重建旧缩略图。网格使用稳定卡片尺寸和缓存参数，导入期间 UI 保持可交互。

## 6. 管理交互

- 宽度不低于 1,000 的主管理窗口显示固定侧栏，其余宽度使用可展开导航。搜索工具栏可用宽度低于 900 时搜索与操作分行，操作按钮可换行；多选工具栏可用宽度低于 600 时使用带说明的图标按钮。正文避让系统状态栏和安全区域。
- 搜索提示为“搜索备注或表情 ID”。搜索框和工具栏拥有输入焦点时，方向键与回车不触发表情使用；网格自身拥有焦点时才处理表情导航和使用。
- 排序和数据更新后按表情 ID 保留键盘焦点。多选标记与独立深色焦点轮廓同时可见，便于判断回车将操作的卡片。
- 网格支持标准与紧凑密度并保存本地偏好。主管理和快速选择窗口均显示加载错误及重试入口，避免将数据库失败显示为空库。
- 桌面卡片悬停显示独立复制按钮，仅写入剪贴板。Windows 复制与自动发送共用互斥锁，独立复制不激活其他窗口、不粘贴或发送回车，且不增加使用次数；macOS 和 Android 成功复制计入使用次数。
- Windows 卡片单击负责复制/粘贴/发送；右键只显示置顶或取消置顶、编辑备注、管理分组、删除表情。
- 删除前显示确认，只删除应用副本，不删除 QQ/微信原文件。
- 多选模式支持键盘全选、批量添加到分组、批量移动和批量删除。添加保留原分组，移动替换原分组；“全部”始终保留。添加对话框支持搜索、多选和新建分组，显示已有归属数量，全部已包含的分组不可重复选择。新建后自动选中该分组。一次添加在一个事务中完成，失败不产生部分关系，成功后保留表情选择。
- 普通拖拽框选替换当前选择，按住 `Ctrl` 追加；Windows 多选时可用鼠标滚轮浏览列表；`Esc`、顶部 `X` 或网格空白处右键清空并退出多选。框选结束不触发延迟单击发送。
- 快速选择窗口默认约 `760×600`，卡片目标约 `112×132`，标题栏可最大化、还原和关闭；主管理窗口保留较舒适布局并保存最近尺寸/最大化状态。
- 托盘左键/双击打开完整窗口并尝试捕获发送目标，右键弹出“打开表情管家”和“退出”；右键打开项只做管理。退出会注销热键、销毁托盘并结束进程。

## 7. 剪贴板、迁移与隐私

Windows 静态图写入 `CF_DIB`/`CF_BITMAP`，GIF 写入 `CF_HDROP` 文件列表；发送使用原生 `SendInput`。兼容性结果记录目标进程、媒体类型和复制/发送状态。

迁移包是版本化 ZIP 的认证加密容器，包含 `manifest.json`、`media/` 和可选 `thumbnails/`。manifest 保存分组、备注、排序字段、使用数据和格式版本。密码至少 8 个字符；密钥由 PBKDF2-HMAC-SHA256（120,000 次）派生，内容使用 AES-GCM-256 认证加密。导入先校验格式、密码、完整性和每个媒体 SHA-256，再恢复记录；重复项安全跳过。

## 8. 首版验收标准

- 热键唤起后，已缓存的快速窗口目标是在约 300ms 内可见。
- QQNT 输入子窗口被重建时，发送仍限定在原 PID，并在实际前台验证通过后才注入按键；目标消失或验证失败时不误发。
- QQNT `personal_emoji\Ori` 导入可预览、按文件选择、去重并进入 `QQ收藏`，顺序与源目录一致。
- 备注“薇欧拉系列”可以用“薇欧拉”搜索到，搜索无结果有明确提示。
- 卡片右键管理菜单动作可用，置顶文案随状态切换。
- Windows 静态图和 GIF 能在 QQ 桌面版完成复制、粘贴和可选回车；微信桌面版进行回归验证。
- 框选支持替换、Ctrl 追加、Esc/右键空白退出，且不产生重复发送。
- 重复启动只有一个 `sticker_manager.exe`；托盘退出后热键、托盘图标和进程释放。
- 重复启动已有实例时恢复主管理模式；不会把隐藏的快速选择窗口直接作为管理窗口展示。
- Android 分享、悬浮面板和 GIF 长按预览不受 Windows 交互改动影响。

## 9. 维护要求

涉及用户行为、数据字段、导入路径、平台桥接或迁移格式的变更，需要同步更新本文件、`ARCHITECTURE.md`、`DECISIONS.md` 和根目录 `CHANGELOG.md`，并补充对应测试或记录无法自动化验证的原因。
