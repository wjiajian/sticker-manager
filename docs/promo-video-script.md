## 二、macOS 录制前准备清单（强烈建议按此配置）

1. **录屏与鼠标丝滑度**
   - 推荐使用 **Screen Studio**（自带 60fps 录制、光标惯性平滑、点击自动局部放大、原生窗口阴影与圆角画布、自动显示 macOS 快捷键浮窗）或 **CleanShot X + Final Cut Pro / DaVinci Resolve**。
   - 动效缓动曲线对齐应用规范：`cubic-bezier(0.22, 1, 0.36, 1)`，局部放大倍数控制在 `1.25x – 1.6x`，避免频繁急推急拉。
2. **桌面与系统环境**
   - 开启「专注模式 / 勿扰模式」，关闭微信/通知弹窗；隐藏桌面杂乱图标与无关菜单栏图标。
   - 桌面壁纸建议使用纯色暖灰 `#E5ECF4` / `#F5F4F0` 或简洁浅色渐变壁纸，让悬浮球、透明预览卡和窗口阴影层次更清晰。
   - 提前准备好一个干净的「模拟聊天窗口」（如空白测试群或自建聊天页，避免暴露真实聊天记录），主窗口默认尺寸 `1280 × 800`。
3. **隔离测试仓库（保护真实数据与隐私）**
   - 请务必用隔离仓库录制，避免泄露真实表情或同步账号信息（详见 [packaging.md](packaging.md#试运行发布版)）：
     ```bash
     release_home="$(mktemp -d /tmp/sticker-release-home.XXXXXX)"
     mkdir -p "$release_home/Library/LaunchAgents" "$release_home/tmp"
     env HOME="$release_home" TMPDIR="$release_home/tmp" \
       /Applications/表情管理器.app/Contents/MacOS/sticker-manager
     ```
   - 建议提前在隔离仓库中准备：
     - **40–80 张高质量、风格统一且带透明底 PNG/WebP 与若干流畅 GIF 动图的表情**；
     - **6–10 个彩色分类**（如：`开心`、`打工`、`摸鱼`、`哈基米`、`困惑`、`美食`、`生气`），并给 3–5 张常用表情写好辨识度高的**配文**（如「收到」「下班」「好股票」）；
     - 预先使用过 8 张表情，让「最近使用 1–8」满格呈现；
     - 收藏 5–8 张表情；
     - 准备一个桌面测试文件夹（内含 2 个子文件夹）和一个中文目录 `.zip` 表情包，用于第 4 章现场导入演示；
     - **同步演示**：使用本地新建的空「同步文件夹」（如 `~/Desktop/DemoSync`）或无真实密钥的界面演示，**切勿露出真实 WebDAV / R2 / S3 密钥与真实 Account ID**。
