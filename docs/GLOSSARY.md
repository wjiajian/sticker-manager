# 表情管理器

跨 macOS 与 Windows 的个人表情管理工具：把表情集中收进一个仓库，归类、快速取用，并在用户自己的设备之间同步。

## 语言

### 表情与仓库

**表情**：
一张可以发送的图片（静态图或动图），是管理的最小单位。
_避免_：贴纸、表情图、sticker

**表情包**：
一次性导入的一组表情（通常是压缩包或文件夹）；导入后拆成独立的表情，本身不作为实体保留。
_避免_：合集、套装

**仓库**：
应用托管的、存放全部表情的唯一位置；表情进入仓库后与用户原来的文件不再关联。
_避免_：图库、资料库、素材库

**配文**：
表情上显示的、可被搜索的文字，例如"收到"；一张表情最多一段配文。
_避免_：文案、字幕、描述

**最近删除**：
已被删除、但 30 天内仍可恢复的表情所在的位置；到期后表情被彻底删除。
_避免_：回收站、废纸篓

**导入结果条**：
主窗口中显示当前导入进度或最近一批结果的区域，可取消导入、查看失败项、给这批表情设分类。

### 整理

**分类**：
用户给表情定的类别名；一张表情最多属于一个分类，分类是扁平的，不能嵌套。名字直接用作同步目录里的文件夹名，所以不能以点开头，也不能含斜杠或 `..`。
_避免_：标签、tag、关键词、文件夹、分组

**未分类**：
没有分类的表情的集合，随分类增减自动进出，不是单独记录的状态。“未分类”是保留名称，不能用作分类名；删除一个分类时，它下面的表情移到这里。
_避免_：未打标签、收件箱

**收藏**：
表情自身带的是或否属性，用来标出用户特别在意的表情；它不是分类。
_避免_：星标、喜欢

### 使用

**表情面板**：
通过全局快捷键、悬浮球或托盘打开，用来搜索和取用表情的小窗口。
_避免_：浮窗、弹窗、快捷窗口

**悬浮球**：
常驻屏幕边缘的圆形入口，用来展开表情面板，也可以接收拖入的图片。
_避免_：悬浮按钮、浮动图标

**使用**：
用户把一张表情复制或拖出去发送的一次行为。
_避免_：发送、点击

**使用次数**：
一张表情在用户所有设备上被使用的总次数。
_避免_：热度、频率

**最近使用**：
合并用户所有设备上的使用，按最近一次使用时间倒序排列的表情列表。
_避免_：历史、最近记录

### 同步

**设备**：
安装了本应用、参与同步的一台电脑。
_避免_：客户端、终端、机器

**存储后端**：
用户提供的、用来在设备之间中转仓库内容的远端存储空间，只能存取文件，不执行任何逻辑。
_避免_：云端、服务器、网盘

**同步文件夹**：
作为存储后端使用的普通文件夹；放在同步盘里时，由同步盘在电脑之间传递其中的内容。
_避免_：云文件夹、共享仓库

**回收站目录**：
存储后端中保留最近删除原图的位置。它对应应用里的「最近删除」，与用户整理表情的分类目录分开。

**操作日志**：
每台设备记录的仓库改动，其他设备用它合并表情及整理、使用记录。
_避免_：同步历史、操作历史

**日志段合并**：
把同一设备序号连续的多个日志文件合成一个，保留全部操作和原序号，只减少文件数和请求数。不同于会丢弃历史的检查点。
_避免_：日志压缩

**同步目标**：
存储后端中供一组设备共同同步的具体位置。同一个存储空间下的不同路径是不同的同步目标。
_避免_：同步地址、同步端点

**同步详情**：
从标题栏状态按钮或左栏同步卡片展开的面板，用于查看同步状态、进度、错误和设备，并进行常用操作；同步设置仍在偏好设置里。

**暂停同步**：
暂时阻止同步而保留目标、凭据和已同步信息。手动暂停跨重启保持；按流量计费的网络暂停只限制自动同步。

### 设置

**偏好设置**：
应用的设置对话框，从侧栏底部、托盘或悬浮球右键菜单打开。设置只存在本机，不同步。
_避免_：设置页、选项

**外观**：
界面的明暗，可选跟随系统、浅色、深色。
_避免_：主题、皮肤、夜间模式
