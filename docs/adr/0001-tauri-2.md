# 用 Tauri 2 作为应用外壳

应用要在 macOS 和 Windows 上常驻一个悬浮球，对安装体积和内存很敏感，而设计稿本身就是 HTML/CSS。所以选 Tauri 2（Rust 后端加系统 WebView），不选 Electron、Flutter，也不选两端各写一套原生代码。

## 考虑过的方案

- **Electron**：两端渲染一致，生态最成熟；但安装包 100 MB 以上，常驻内存 150 MB 以上，不适合一直开着的悬浮球。
- **Flutter Desktop**：渲染一致；但设计稿要整体重写，透明悬浮窗和多窗口在桌面端还不成熟。
- **SwiftUI + WinUI 3**：体验最好；但要维护两套代码。

## 后果

- macOS 的 WKWebView 和 Windows 的 WebView2 有少量差异，样式要在两端都检查。
- 剪贴板、文件、同步这些系统能力写在 Rust 里。
- macOS 上悬浮球要浮在全屏应用上面、又不抢焦点，必须用 NSPanel（`tauri-nspanel`）；Windows 用置顶、不激活的窗口。
