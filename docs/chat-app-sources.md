# 聊天软件图片来源验收（Issue #7）

## 安全的验收环境

使用 Debug 版，给测试实例配置独立的临时仓库。关闭诊断或测试结束后退出实例。不要使用真实表情库或含个人聊天、身份信息的图片样本。日志只记录提供的格式、操作、结果码，不贴聊天截图、图片内容、文件名或路径到 Issue。

macOS：

```bash
STICKER_LIBRARY_DIR="$(mktemp -d)" STICKER_DROP_DIAGNOSTICS=1 pnpm --dir frontend tauri dev
```

Windows PowerShell：

```powershell
$env:STICKER_LIBRARY_DIR = Join-Path ([System.IO.Path]::GetTempPath()) ("sticker-drop-" + [guid]::NewGuid())
$env:STICKER_DROP_DIAGNOSTICS = "1"
pnpm --dir frontend tauri dev
```

macOS 14 及以上系统可能询问是否允许访问其他 App 的数据；由用户自行决定是否允许，拒绝时记录为未验收，不改系统设置。剪贴板操作由用户使用非隐私样本完成，不由测试程序写入真实剪贴板。跨应用真实拖放无法在后台完成，若接管屏幕须记录。

## Issue #7 关闭标准

上述真实样本覆盖完成后，所有允许向外导出并提供支持格式的样本应成功，只有内部拖拽或只提供远程地址的样本明确拒绝；两平台主窗口及悬浮球文件路径导入与分类拖拽仍正常。无法提供原始动图时记录来源限制，不能算原始动图导入成功。日常自动检查通过并不代替真实来源验收。
